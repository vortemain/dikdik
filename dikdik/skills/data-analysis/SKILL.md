# Data Analysis

1. Inspect column meanings, types, units, missing values and sampling before calculating. Preserve the source and distinguish inferred types from documented schema.

2. State the question and choose transformations that answer it. Handle duplicates, time zones and join cardinality explicitly; check totals before and after aggregation.

3. Use reproducible code or formulas and report uncertainty where sample size or data quality limits the result. Correlation does not establish a causal effect.

4. Validate representative rows and edge cases. Present a concise finding with units, provenance and limitations; do not claim the runtime can render or edit file formats without the required tools.
