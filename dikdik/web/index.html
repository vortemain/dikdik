          General
          
      
          
        
          Appearance
          Match your system, or pick light or dark.
          
        
          Confirm actions
          Ask before the agent runs a tool. “Risky only” asks for commands that delete, install, use the network or rewrite history.
          
        
          Condense long conversations
          When a conversation outgrows the history budget, older turns are replaced with a summary written by your model.
          
        
          Sound when a task finishes
          A short chime when a run ends while you are in another tab or window.
          
        
          Git identity
          Name and email for commits made from the Git tab. Leave blank to use your Git configuration.
          
          
          
        
          Conversation titles
          After the first finished turn, name the conversation with a short model-written title. Only conversations that already share content with a model are titled.
          
        
          Browser tools
          Enable public web captures. Each task or manual capture still needs your approval.

          The only folder Dikdik may read. Candidates are written to the private data directory.
