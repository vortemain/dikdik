# Dikdik v0.1.0 — developer preview

Dikdik is an MIT-licensed local engineering workspace with agent tools, durable
conversations, checkpoints, Undo, skills, hooks and configurable model providers.

## Included

- 34 bundled skills and a central hook engine for `task.started`,
  `context.building`, `tool.before`, `tool.after`, `tool.failed`, `task.completed`.
- Hook priorities, allow/block decisions, timeouts, structured outputs and
  durable traces. Plugin hooks cannot grant permissions or bypass security.
- Bounded provider recovery, malformed-response regeneration, non-streaming
  fallback and safer context continuity and resumable verification.
- Local project checks with honest test/static/unavailable status.
- Updated conversation rendering, workspace files, dialogs and provider icons.
- Complete MIT and bundled third-party notices in distribution archives.

## Downloads and installation

Requires Python 3.13 or newer. Download the wheel and `SHA256SUMS.txt` from this
release. Compare its SHA-256 hash before installation:

```powershell
Get-FileHash .\dikdik-0.1.0-py3-none-any.whl -Algorithm SHA256
python -m pip install .\dikdik-0.1.0-py3-none-any.whl
dikdik --version
dikdik C:\Projects\my-app
```

On Linux/macOS, download both archives and run `sha256sum -c SHA256SUMS.txt`
(macOS: `shasum -a 256 -c SHA256SUMS.txt`). The wheel ships the Python indexer;
the source archive includes the optional Rust indexer and its build script.
No Node.js/Bun or Rust installation is required to run the wheel.

## Preview limits

This is a developer preview. Local mode executes approved actions with your user
permissions. Use trusted projects and review the documented permission modes.
Docker images, browsers, ACP CLIs, external accounts and model access are separate
operator prerequisites. Provider-generated tool calls can still fail after the
bounded recovery limit. Live Docker boundary tests and independent production
security review remain open. See `SECURITY.md`, `LICENSE-STATUS.md` and the
verification record in the source archive.
