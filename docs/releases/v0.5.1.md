# Dikdik 0.5.1 — chat that researches, and conversations that keep their files

## Chat is a general assistant that looks things up
- **Web search works with no setup.** Without a Tavily key, Dikdik searches with
  DuckDuckGo (then Wikipedia). Chat always has web search and page reading, so it
  no longer says it has no search tool.
- **Research before answering.** Questions about companies, people, products,
  recent events, statistics, or health, legal and financial specifics are searched
  with several queries; the best 2–4 sources are read, cross-checked and cited.
- **Natural replies.** A greeting gets a friendly greeting, not a list of features.
  Coding-only rules no longer leak into chat.

## Conversations keep their files
- Files attached to earlier messages stay in the conversation after a pause, a stop
  or a follow-up, in Chat and in Code. The model knows what was attached and can
  reopen each file by path with read_document, read_image or statistics.
- Chats can be paused and resumed exactly where they stopped, as a chat.

## Upgrading
Nothing to configure. A Tavily key (Settings → Models) is still used first when
connected.
