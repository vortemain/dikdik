# Dikdik 0.5.0 — chats without projects, research-grade documents and data, images for every model

Start a chat straight away — no project to pick — and give it your Word, Excel,
PDF or PowerPoint files: Dikdik reads them in full, runs real statistics, writes
Word reports with native charts, and lets you preview every file inside the app.
Text-only models can now work with images too.

## What's new

### Chat and Code tabs
The sidebar opens on two clear tabs. **Chat** starts a conversation immediately and
lists your chats from every project; **Code** shows the project picker and that
project's tasks. Each chat has its own private folder for its attachments and the
files it creates, and deleting a chat deletes them.

### Documents that are actually read
- Fixed: attached Word, Excel and PDF files used to reach the model as "could not
  read", and spreadsheets were cut to 40 columns.
- `read_document` reads Word, PDF, Excel, PowerPoint, OpenDocument, RTF, EPUB and
  HTML in full, with an outline, paging and phrase search. Scanned PDFs are read
  with OCR.
- `statistics` runs frequencies, Likert summaries with Cronbach's alpha, crosstabs
  (chi-square, Cramér's V, Fisher), t-test/Mann-Whitney, ANOVA/Kruskal-Wallis,
  Pearson/Spearman and linear or logistic regression. Results match SciPy and
  statsmodels.
- `create_document` writes Word files (title page, table of contents, captions,
  page numbers, native editable charts), Excel workbooks and text files.

### Preview inside Dikdik
Created and attached files open in a preview: formatted Word pages with pictures
and charts, slides, PDFs and images, with Download and Open in Word/Excel.
Spreadsheets and CSV files get a real spreadsheet view that fits phones, tablets and
desktops: column letters, row numbers and a header row that stay in place, a cell
bar for long values, search and sheet tabs. Old Excel 97-2003 (.xls) workbooks are
read as well.

### Images for text-only models
Dikdik reads the text in images with the OCR built into Windows (Tesseract on
macOS/Linux) and, when one of your models can see, has it describe tables, charts
and screenshots. Models that refuse images get that text instead, and the new
`read_image` tool reads images, pictures inside documents and scanned pages.

## Upgrading
Nothing to configure. To have charts and photos described (not just their text
read), pick a vision-capable model under Settings → General → Read images with.
