# Dikdik 0.7.1 — security update for drawings and formulas

Everything in [0.7.0](v0.7.0.md) — chalkboard drawings, function plots, science
sketches, typeset formulas and literature search — with up-to-date libraries.

## Security
- **Mermaid 11.17.2** (from 11.9.0) fixes published advisories: label and class
  definition sanitisation, CSS injection, and denial of service in XY, Gantt and radar
  diagrams. Dikdik already shows diagrams as images under a strict content policy, so
  no script could run, but the fixed engine is now bundled.
- **KaTeX 0.18.11** (from 0.16.22) and **lodash-es 4.18.1** close prototype-pollution
  advisories.

## Drawing fixes
- Sketches no longer fail on common model slips in their JSON (a missing `"to"` key,
  trailing commas); free text is centred on its point and always fits on the board,
  with less empty space around drawings.
- Loading the handwriting font times out instead of waiting forever.

## Upgrading
Nothing to configure.
