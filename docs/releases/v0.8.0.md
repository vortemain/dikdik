# Dikdik 0.8.0 — a sharper, leaner agent that finishes the job

## Long tasks finish instead of burning tokens
A thesis-analysis chat used to spend millions of tokens re-reading the same document
and stop with nothing. Now:
- **Full working memory in chat.** Chats and plans get the same working budget as
  agent tasks, and condensing older context keeps what was learned from documents,
  statistics and the web.
- **Working notes and a rolling checkpoint.** The agent writes down the facts it
  needs (objectives, sample size, key results), and a checkpoint of goals, decisions,
  numbers, files and sources carries through every condensation. Numbers, links and
  file names are checked to survive it.
- **No more reading loops.** Re-reading parts of a document already read, repeated
  actions and back-and-forth patterns are noticed early, and the agent moves on.
- **Long documents are written in parts.** A report or chapter is drafted section by
  section and built into the Word file at the end.

## Pays only for what a question needs
- **Native Claude connection** with prompt caching, adaptive thinking you can see,
  and a working effort setting. Anthropic profiles no longer go through the
  OpenAI-compatible endpoint, which had no caching and hid the thinking.
- **Simple questions get one quick reply.** Greetings and short factual questions are
  answered directly; deep work gets a plan and checks.
- **Leaner requests**: a stable prompt that caches well, large tool output kept in
  files instead of in the conversation, and only the skills a task needs.

## Thinks, acts and checks like an expert
- **Code in any installed language**: Python, JavaScript/TypeScript, PowerShell,
  Bash, Go, Rust, Java, C# and more. Programs can call Dikdik's own tools (documents,
  statistics, the web), and every program still waits for your approval.
- **An adaptive shell** that speaks PowerShell or POSIX, runs in the right folder and
  moves long commands to the background instead of killing them.
- **Answers are checked before you see them**: deliverables exist, cited sources
  were actually read, and reported numbers match the analysis.
- **A researcher helper** reads widely in its own space and returns a short report.

## Secure by default
Everything the agent writes or runs is scanned first: command injection, unsafe
evaluation, disabled certificate checks, committed keys and more are fed back for a
fix before the code runs or is delivered. Credentials are never written to files and
are sealed when you provide them.

## Learns from experience
Dikdik remembers your preferences and project facts across chats (for example
British English and APA 7th edition), can search past conversations, and proposes
improvements to its skills after a correction or a recovery. Skill changes always
wait for your approval; you can view, edit and clear memory in Settings.

## A new chat space
Thinking you can expand, compact tool steps, a pinned plan checklist, numbered
citations, a cost and context meter, and the ability to steer a run while it works.
Commands are available in every chat, each one asked first. The welcome page centres
the message box, with a fresh workspace look.

## Fixed
- An empty Anthropic balance was reported as "Check the model and its settings"; it
  now says the account is out of credit.
- Providers that reuse tool-call IDs, stream thinking in unnumbered pieces, or drop
  long replies no longer end a task.
- A chat asked to verify its work by running code is no longer blocked by the
  project test gate meant for code changes.

## Validation
- The Python suite (1,459 tests, 9 skipped) passes on Windows with Python 3.13; the
  frontend typecheck, 238 web tests and build pass, and the committed bundle matches
  the build.
- Live runs used free stand-in models, not Claude: the thesis analysis now finishes
  with a correct Word document, and research, teaching, maths, run-and-verify code,
  data analysis, memory recall, building a tool with tests, fixing a bug and an
  insecure coding request all complete.
- Not yet run live on Claude; prompt-caching savings are verified with tests only.

## Upgrading
Nothing to configure. Your data is migrated on first start.
