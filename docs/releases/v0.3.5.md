# Dikdik 0.3.5 — no Docker, nothing extra to install, and a faster, verified agent

Dikdik now runs entirely on your computer with nothing else to install: Docker is
gone, commands work on Windows without Git Bash, and every provider (Nebius
included) keeps your key after a restart. The agent is faster, checks design work
in a real browser, and was measured end to end on live build-from-scratch tasks.

The v0.3.4 tag's build failed its checks and was never published; 0.3.5 is that
release plus the fixes listed under **Reliability**.

## Downloads and installation

- **Windows x64:** run `Dikdik-0.3.5-Windows-x64-Setup.exe`. Requires the Microsoft
  Edge WebView2 Runtime. Installs into the per-user Programs directory.
- **macOS:** open the DMG matching its named CPU architecture and drag Dikdik to
  Applications. This preview is not Developer ID signed or notarized; standard
  Gatekeeper restrictions apply. Native notification permission is required.
- **Linux amd64:** install `Dikdik-0.3.5-Linux-amd64.deb` with
  `sudo apt install ./Dikdik-0.3.5-Linux-amd64.deb`. Targets Ubuntu 24.04 and newer
  compatible Debian systems with a graphical desktop.
- **Python:** install `dikdik-0.3.5-py3-none-any.whl` with Python 3.13+. The wheel
  includes the browser UI; its optional `[desktop]` extra adds the desktop host.

Desktop bundles include Python and matching Chromium. Close an existing Dikdik
desktop before installing the update. The same private data location is retained;
back it up before updating. `SHA256SUMS.txt` covers all uploaded files.

## Changes

- **No Docker.** Tests and commands run in local mode on this computer, under your
  permission mode, with time and output limits and process-tree supervision. Classic
  mode syntax-checks an isolated copy and runs nothing; scheduled runs are
  syntax-only, and saved Docker runs were migrated to that. Requests asking for
  `docker` are refused with the alternatives.
- **Nothing extra on Windows.** Without Git Bash, agent commands are translated for
  PowerShell (`&&`, `||`, `/dev/null`, `rm -rf`, `mkdir -p`, `ls -la`, `$NAME`
  secrets) with real exit codes; `npm.ps1` runs under the default script policy;
  Python output is UTF-8; Dikdik's own Python is used when PATH has none.
- **Providers.** Real Nebius logo; xAI shows its own mark. Provider keys are saved
  encrypted again and stay connected after a restart (since 0.3.2 they lived only
  in memory for up to 8 hours). The invite-only sponsored gateway was removed.
- **Connecting a model** is one focused screen: pick a provider, paste the key, pick
  a model, with nothing opening below the fold and "In use" showing what is active.
- **Calmer chat page.** The home screen is the greeting, four suggestions and the
  message box; turn statistics show on hover; the sidebar lost its duplicate project
  block; list filters appear once there is something to filter; no clipped text.
- **Faster, steadier agent.** LF/CRLF-tolerant edits, multi-edit and overwrite,
  plain-text reads, a syntax gate limited to touched files, compaction that frees
  real room, smaller checkpoints, one SQLite connection per run, pre-existing
  failure baselines, a project outline and remembered commands.
- **Design work verified in the browser.** `preview_app` takes `focus` and
  `inspect`, shows screenshots to the model, runs an accessibility audit and
  compares with owner-accepted visual baselines; previews of the project's own dev
  server no longer need public-web approval.
- **Panels.** Terminals open as tabs in the Terminal panel, browsing without a
  conversation stays in the Browser panel, the Planner lists every plan, and the
  Task List is always available.
- **Engineering tools.** Security scan, requirements and release gate, SBOM with a
  working licence policy, backup/restore, architecture map, load, DAST and fault
  tests, visual regression, parallel writers, CodeQL and weekly mutation testing.
- **Safety.** A turn whose command changes Dikdik's own files is stopped; approved
  secrets are redacted from local command output.
- **Reliability.** A fault-test "down" dependency now refuses connections at once on
  Linux instead of accepting and resetting them; the user's answer to an agent
  question is always recorded before the agent continues; the plan list's SQL goes
  through the identifier allowlist; benchmark exports have a timeout.

## Validation and limits

The full Python suite and the frontend tests and typecheck pass on Windows; CI runs
them on Windows and Linux. On live runs with OpenRouter GLM-5.2, 23 of 24 benchmark
runs succeeded across eight tasks (including three apps built from an empty folder
and three `parallel_edit` runs); the one failure exposed a bug fixed in this release,
after which that task passed 3 of 3. These are single-model results, not a general
success rate. Binaries are unsigned developer previews, not a claim of production
readiness. Local mode runs commands with your user's rights; see SECURITY.md.
