# Dikdik 0.4.0 — chat mode, document viewers, diagrams, and a smarter welcome

A new Chat mode for research and analysis conversations, real document viewers
for PDF/Word/Excel/PowerPoint/CSV, Mermaid diagrams that render as SVG, an
adaptive welcome screen with rotating greetings, local auto-sign-in, and a
major module split of the frontend.

## What's new

### Chat mode
A Chat / Code selector in the sidebar switches between agentic coding (edits,
commands, tests) and research conversations. Chat mode can read and create
files, analyze data tables, research the web with sources, load skills, and —
with explicit approval — run shell commands for data work. Each command needs
your approval, the same as code mode.

The chat agent has an education-aware system prompt that detects whether you're
a student, researcher, or developer and adjusts depth accordingly. It explains
concepts step by step, cites sources as plain URLs, distinguishes reasoning
from estimates, and creates files (notes, analysis, documentation) when they
would help.

### Document viewers
Dikdik now renders PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV
and TSV files in the editor with a real document viewer — not raw text. PDF
opens in a same-origin iframe; Word shows headings, paragraphs and tables;
Excel and CSV show a grid with sheet tabs; PowerPoint shows slide cards.

### Ask about a file
A side drawer under any open file lets you ask questions about it. If a
conversation is open, it's a side question answered from that conversation;
if none is open, a chat conversation carries the Q&A. Selected text is
included as context.

### Rewind
Rewind any conversation to just before one of your messages. The message and
everything after it is removed; your files are untouched.

### Mermaid diagrams
\`\`\`mermaid code blocks in agent responses render as professional SVG
flowcharts and sequence diagrams — no dependencies, pure vanilla TypeScript.

### Adaptive welcome
The welcome screen rotates through greetings in French and English and shows
context-aware suggestions that adapt to the workspace (data files → "Analyze
my data", tests → "Review my tests", markdown → "Explain this project").

### Local sign-in
Opening Dikdik on your own computer no longer shows the "paste a sign-in
token" page. The browser auto-signs-in via a CSRF-protected local endpoint;
the token is still required for remote deployments.

### Attachments
The attachment limit is now 10 MB. Document attachments have their text
extracted and inlined for the model. The file-type restriction was removed.

### Module split
`app.ts` was split from ~5000 lines into 8 focused modules: `dom.ts`,
`code-render.ts`, `chat-widgets.ts`, `doc-viewer.ts`, `ask-drawer.ts`,
`conversation-mode.ts`, `welcome.ts`, `mermaid.ts`.

### Thinking fold
Agent noise ("inspected files", "using skills", "model routed", "thinking")
is collapsed into a single "Thinking" block.

### Statistical analysis
`analyze_data` tool: CSV/TSV/JSON/XLSX statistics (counts, means, medians,
standard deviation, quartiles, group-by aggregates, Pearson correlations).

### Web cards
`web_fetch` and `web_search` results render as rich cards with source chips,
page titles, metadata and extracted text — not raw JSON.

## Downloads and installation

- **Windows x64:** run `Dikdik-0.4.0-Windows-x64-Setup.exe`. Requires the Microsoft
  Edge WebView2 Runtime. Installs into the per-user Programs directory.
- **macOS:** open the DMG matching its named CPU architecture and drag Dikdik to
  Applications. This preview is not Developer ID signed or notarized; standard
  Gatekeeper restrictions apply. Native notification permission is required.
- **Linux amd64:** install `Dikdik-0.4.0-Linux-amd64.deb` with
  `sudo apt install ./Dikdik-0.4.0-Linux-amd64.deb`. Targets Ubuntu 24.04 and newer
  compatible Debian systems with a graphical desktop.
- **Python:** install `dikdik-0.4.0-py3-none-any.whl` with Python 3.13+. The wheel
  includes the browser UI; its optional `[desktop]` extra adds the desktop host.

Run `dikdik` from a project folder, or `python -m dikdik.server --workspace .`
from the terminal.
