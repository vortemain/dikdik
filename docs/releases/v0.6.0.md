# Dikdik 0.6.0 — formulas and diagrams, built for teaching

Dikdik now explains like a tutor: mathematics is properly typeset, processes are drawn
as real diagrams, and Word documents carry real equations.

## Formulas
- Typeset with KaTeX, bundled so it works offline: `$...$` and `\(...\)` inline;
  `$$...$$`, `\[...\]`, `\begin{align}` and ```` ```math ```` blocks as centred
  equations — in replies, tables, Markdown files and previews.
- Prices ("$5 and $10"), shell variables and code are never mistaken for maths.
- Copy LaTeX on every display equation; screen readers read formulas through MathML.

## Diagrams
- The real Mermaid engine, bundled and loaded only when a reply has a diagram:
  flowcharts, sequence, class, state, entity-relationship, mind maps, timelines, Gantt,
  pie, quadrant, XY charts, journeys, Git graphs, Sankey and block diagrams.
- Themed for light and dark; Copy source, SVG and PNG download, full-screen zoom.
- Common model slips (labels with brackets or punctuation) are repaired automatically.

## Word documents
- LaTeX in `create_document` becomes native, editable Word equations: fractions, roots,
  powers and indices, sums, integrals, limits, accents, matrices and aligned lines.
- `read_document` reads equations back as text.

## A tutor's approach
Chat starts from intuition, defines every symbol, works an example with real numbers,
points out the common mistake, ends with a practice question, writes all maths in
LaTeX, and draws a diagram whenever it explains how something works.

## Fixes
- A display formula followed by text on the same line (`$$...$$ ✓`) no longer swallows
  the lines after it.

## Upgrading
Nothing to configure.
